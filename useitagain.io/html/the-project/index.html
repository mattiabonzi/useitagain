USEITAGAIN.IO

What is this project?

This project essentially consist in a simple installer script, some guides and a repository of .deb packages with the aim to make it easy to install useful software on an Android device.

The mission

The mission and aim of this project is to "save" and re-use as many as possible old device, for as many as possible different task.

Right now the bundled software are all about Smart Home Automation (or smart thing management).

An old, or partially broken, device is usually left to old and dust in a drawer or even worse, discarded. According to the WEEE Forum, 5.3 billion smartphone are discarded every year.

I believe that many of that device can simply be repurposed for new task instead of been discarded. This also prevent the need of buying a new device (like a RaspberrryPI and similar)

The problem to solve

Android is, on the paper, an Open Source Operating System based on Linux Kernel, so it's theoretically possible to compile and install almost everything you could install on a normal Linux machine.

The only real problem is that nearly nobody cares of distributing and maintaining packages for "Android Linux", for obvious reason (few people use them).

Thanks to the great work of the Termux development team, it's possible to install a great number of packages, but not without headaches.

And here is where this project comes in, collecting everything you need to turn your old smartphone in a new shiny server for whatever you need.

Contribute

If you want to help to maintain the project, improve something, add new software or anything else get in contact at contrib@useitagain.io

If you encounter a problem, please open an issue, including as much information as you can about your problem and device.
